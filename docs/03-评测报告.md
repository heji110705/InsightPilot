# InsightPilot 评测报告（结果集等价）

> 判定口径：列数相同、列名不比较、行序不比较（多重集）、数值 1e-6 相对容差、字符串去首尾空白且大小写敏感、None 与空串不等。
> 所有指标由 `scripts/run_eval.py` 实跑写入 `docs/eval_results.json` 后渲染，没有手填值；第 5.2 节标注为直接 SQL 抽检的数字除外。

> **先看重复性再读表**：同一配置重复运行的 EX 极差在本项目实测为 3.3 个百分点（见 `docs/03b-重复性检验.md`）。本表是**单次运行**结果，任何小于该量级的组间差异都不应被解释为模块效果。

## 1. 结论

4 组配置在 60 题上的 EX 分别为 full 41.7%、no_critic 45.0%、no_schema 38.3%、single 40.0%；最高 45.0%（no_critic），最低 38.3%（no_schema），极差 6.7 个百分点。

full 比 no_schema 高 3.3 个百分点（41.7% vs 38.3%），差异对应 SchemaLinker 是否按相关性挑指标。no_critic 与 full 的差距为 -3.3 个百分点，`attempts>1` 的题数为 1 次。

本次为真实模型模式（`llm` / api），数字可代表该模型在该提示词下的表现，但不可跨模型版本或提示词版本直接比较；局限性见第 6 节。

## 5. 低分排查记录

模型模式下的失败构成（按 `compare` 给出的差异类型归类，每条可回查）：

| 差异类型 | 题数 | 常见含义 |
|---|---|---|
| 列数不同 | 26 | 输出列数不一致，多为模型多给了未被问到的描述列 |
| 单元格不等 | 5 | 行列数都对但取值不同（口径或聚合层级差异） |
| 行数不同 | 4 | 过滤条件或 TOP-N 阈值与预期不一致 |

> 分类只是把差异摊开，不等于根因。同一类里可能同时存在「多给了一列」和「少给了关键列」，必须回看第 4 节的逐题明细。

本次所有配置的 EX 均不低于 0.3 的防呆线，未触发低分专项排查；评测框架的自检项（`cache_hits`、`attempts_gt1`、失败分布）仍记录在 JSON 与上表中。

## 6. 局限性声明

- 本报告为 api 模式结果，但模型版本、温度、提示词变化都会改变数字，跨版本不可直接比较。
- **数据快照极窄**：仓库只有 2026-10-18 与 2026-11-01 两天（且都是周日），T4 时间类题目没有「上个月/按周趋势」的真实跨度，区分度有限；任何关于时间分析的结论都不具备统计意义。
- **样本量小**：60 题、每题权重 1.67%，百分比的 95% 置信区间约 ±12 个百分点；两组相差 1–2 题（1.7–3.3 个百分点）不能说明模块优劣。
- **结果集等价 ≠ 语义正确**：列名与行序不参与比较，同一数字的不同口径（如收藏次数 vs 收藏人数）可能都被判为「等价」；评测只能证明「算出了同一张表」，不能证明「选对了业务口径」。
