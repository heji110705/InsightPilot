# 重复性检验与消融可信度

> 数据来源：3 个运行目录，共 8 次配置运行；模式 api。全部数字由本脚本从各目录的 `eval_results.json` 汇总，无手填。

## 1. 结论

同一配置重复运行的 EX 极差最大为 **3.3 个百分点**（41.7% ~ 45.0%，配置 `full`）。

四组配置的平均 EX 落在 39.2% ~ 44.2% 之间，极差 5.0 个百分点。

组间极差大于重复波动，差异**具备进一步验证的价值**，但 n 仍然很小（每配置 2 次），不能作为显著性结论；如需下判断应扩到每配置 ≥5 次。

## 2. 逐配置明细

| 配置 | 运行次数 | EX 各次 | 均值 | 极差 | 首答正确均值 | p50 均值 |
|---|---|---|---|---|---|---|
| full（6 Agent 全开） | 2 | 41.7% / 45.0% | 43.3% | 3.3pp | 43.3% | 5615 ms |
| no_critic（去掉自检） | 2 | 45.0% / 43.3% | 44.2% | 1.7pp | 44.2% | 5419 ms |
| no_schema（去掉语义层检索） | 2 | 38.3% / 40.0% | 39.2% | 1.7pp | 39.2% | 5431 ms |
| single（单 Agent，无检索/重试/自检） | 2 | 40.0% / 38.3% | 39.2% | 1.7pp | 39.2% | 5465 ms |

> 极差单位 pp = 百分点。波动带 **±1.7pp**（取各配置极差的半宽，样本量小时这是粗略上界而非置信区间）。

## 4. 逐题稳定性

同一题的判定在多次运行间是否翻转，是判断单次评测可信度的最直接证据。下表只统计出现翻转的题（同配置内部比较，不含跨配置）：

| 配置 | 题号 | 各次判定 |
|---|---|---|
| full | Q02 | 错 / 对 |
| full | Q17 | 错 / 对 |
| no_critic | Q04 | 对 / 错 |
| no_schema | Q39 | 错 / 对 |
| single | Q17 | 错 / 对 |
| single | Q28 | 对 / 错 |
| single | Q36 | 对 / 错 |

共 7 个「配置×题目」出现判定翻转；这些题在单次运行里被算作正确或错误都带有偶然性，做单题分析时应避开。

## 5. 方法学结论（可写进简历/面试）

1. `temperature=0` 不等于可复现：以 `no_critic` 为例，重复运行间 SQL 文本完全一致的题数是 30/60（50%），模型服务端的批处理与路由都会引入噪声。
2. 60 题样本下，单配置 EX 波动约 ±1.7pp，因此**任何小于该量级的消融差距都不值得解释**，更不该写成因果。
3. 若要主张模块有效，正确做法是每配置多次运行取均值并做区间估计，或把评测集扩到数百题——本报告选择把噪声如实暴露，而不是挑一次好看的数字。
